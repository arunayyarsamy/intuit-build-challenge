# Intuit Build Challenge

This repository contains the solutions for the Intuit Build Challenge, divided into two main assignments.

## Assignments

### 1. Producer-Consumer Application (`assign1`)
A robust, multi-threaded implementation of the Producer-Consumer pattern in Java.
- **Key Features**: Thread safety, blocking queues, wait/notify mechanisms, and graceful shutdown.
- **Documentation**: [Read detail](assign1/README.md)

### 2. Sales Analytics System (`assign2`)
A functional programming-oriented sales analytics tool processing CSV data.
- **Key Features**: Java Streams, `parallelStream` optimization, immutable data models, and comprehensive metrics (Revenue, Profit, Top Products).
- **Documentation**: [Read details](assign2/README.md)

## Getting Started

Each assignment is a self-contained Maven project. Please refer to their respective README files for specific build and run instructions.

```bash
# Example: navigating to assignment 1
cd assign1
mvn test
```
